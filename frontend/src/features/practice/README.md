## โครงไฟล์

| ไฟล์ | ทำอะไร |
|---|---|
| `PracticePage.jsx` | หน้า `/practice` |
| `mock/questions.js` | โจทย์ตัวอย่าง 3 ข้อ |

ตรรกะแบบทดสอบ (ตอบ/ข้อถัดไป/คะแนน) อยู่ใน `features/quiz` — ใช้ร่วมกับบทเรียน

## เชื่อมกับ

quiz, progress (♥ และบันทึกผลด้วย `recordQuizResult`), sign-ai (อนาคต: โหมดทำท่าให้กล้องตรวจ)

## หมายเหตุ

- เสียงใช้ Web Speech API ของเบราว์เซอร์ (ฟรี) — ควรเปลี่ยนเป็นไฟล์เสียงจริงภายหลัง
- ภาพประกอบยังเป็น placeholder ห้ามใช้ตัวการ์ตูนที่มีลิขสิทธิ์
