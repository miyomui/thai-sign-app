## ตัวเลือกเทคโนโลยี (ฟรีทั้งหมด)

| ตัวเลือก | ข้อดี | ข้อจำกัด |
|---|---|---|
| WebXR (ในเบราว์เซอร์) | ไม่ต้องติดตั้งอะไร | iOS Safari ยังรองรับจำกัด |
| `<model-viewer>` (Google) | ง่ายมาก รองรับ AR บน Android/iOS | ต้องใช้โมเดล .glb/.usdz (ขอทีม Unity export) |
| AR.js | ใช้ marker ได้ | ภาพไม่นิ่งเท่า WebXR |

ตกลงกับทีม Unity ว่าจะ export โมเดลรูปแบบไหน แล้วค่อยเลือก (ต้องขออนุมัติทีมก่อนติดตั้ง package)
