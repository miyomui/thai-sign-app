# app/ — โครงแอป (ไฟล์กลาง)

| ไฟล์ | ทำอะไร |
|---|---|
| `routes.jsx` | รายการหน้า (path → Page ของแต่ละ feature) |
| `providers.jsx` | Provider ทั้งหมด (Toast, Auth, Progress, WordModal) |
| `layout/AppShell.jsx` | Sidebar + Topbar + เนื้อหา, ย่อเมนูอัตโนมัติเมื่อจอ < 820px |
| `layout/Sidebar.jsx` | เมนูซ้าย |
| `layout/navItems.js` | รายการเมนู |
| `layout/Topbar.jsx`, `layout/SearchBox.jsx` | แถบบน + ช่องค้นหา |

แก้ไฟล์ในโฟลเดอร์นี้ = กระทบทุกหน้า → แจ้งทีมก่อนเสมอ
