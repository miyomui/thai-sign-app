# ออกแบบหน้าแรก (Home) — ระบบเรียนรู้ภาษามือไทย 3D + AR

> เอกสารนี้ออกแบบจาก Reference wireframe (หน้า "สวัสดี") + พาเลตต์จาก Moodboard + ขอบเขตโครงงาน (คำศัพท์ 50–100 คำ, ประโยค 10–20 รูปแบบ, Unity WebGL, AR ผ่านเว็บ)
> หมายเหตุ: Reference เป็นแค่ตัวอย่างเพื่อให้เห็นภาพ ส่วนนี้คือเวอร์ชันที่ปรับให้ใช้งานจริงได้

## 1. เป้าหมายของหน้าแรก

| เป้าหมาย | วิธีตอบ |
|---|---|
| ให้ผู้ใช้เริ่มเรียนได้ใน 1–2 คลิก | การ์ด "คำศัพท์แนะนำวันนี้" + ปุ่ม "เริ่มเรียน" |
| ค้นหาคำศัพท์ได้เร็ว | ช่องค้นหาด้านบน + หมวดหมู่ |
| เห็นภาพรวมเนื้อหา | การ์ดหมวดหมู่ (ทักทาย / ซื้อขาย / ขอความช่วยเหลือ ฯลฯ) |
| ดูท่าทางแบบ 3D ได้ทันที | Avatar Viewer (Unity WebGL) ในหน้าแรกเลย |
| ติดตามความก้าวหน้า | แถบ Progress + คำศัพท์ที่บันทึกไว้ |

**ผู้ใช้หลัก:** นักศึกษา/บุคคลทั่วไปที่ไม่มีพื้นฐานภาษามือ (กลุ่มทดสอบ 20–30 คน)

## 3. Design Tokens (อิงจาก Moodboard)

### 3.1 สี

| Token | ค่า | ใช้กับ |
|---|---|---|
| `--color-primary` | `#8A9A6E` เขียวเสจ | ปุ่มหลัก, เมนู active, ไอคอนสำคัญ |
| `--color-primary-strong` *(เพิ่ม)* | `#5E6E47` | ข้อความขาวบนพื้นเขียว (ให้ผ่าน contrast) |
| `--color-secondary` | `#B5C49A` เขียวอ่อน | chip, พื้นการ์ด, sidebar item ปกติ |

| `--color-surface` | `#F5D9E6` ชมพูจาง | พื้นการ์ดเสริม, chip หมวดหมู่ |
| `--color-bg` | `#FBF6EC` ครีม | พื้นหลังหน้า |
| `--color-highlight` | `#D4AF37` ทอง | ดาว / เสร็จสมบูรณ์ / badge พิเศษ |
| `--color-text` | `#2F3A26` เขียวเข้มเกือบดำ | ข้อความหลัก |
| `--color-card` *(เพิ่ม)* | `#FFFFFF` | พื้นการ์ดหลัก (ให้แยกจากครีม) |
| `--color-border` *(เพิ่ม)* | `#E3DCCB` | เส้นขอบบาง ๆ |
| `--color-text-muted` *(เพิ่ม)* | `#5B6650` | ข้อความรอง |

> ⚠️ **Contrast:** `#2F3A26` บน `#8A9A6E` ได้ ≈ 4:1 (ผ่านเฉพาะตัวอักษรใหญ่/ตัวหนา) → ถ้าใช้ตัวอักษรขาวบนปุ่มเขียวให้ใช้ `--color-primary-strong` แทน (≈ 5.5:1) ค่าเหล่านี้เป็นการประมาณ ควรตรวจซ้ำด้วยเครื่องมือ contrast checker ก่อน handoff

### 4.3 Greeting + Progress
- ข้อความ "สวัสดี, <ชื่อ>" (ถ้ายังไม่ล็อกอิน: "ยินดีต้อนรับ" + ปุ่ม เข้าสู่ระบบ)
- Progress bar สี `accent` บนราง `surface` พร้อมข้อความ "เรียนแล้ว 12 / 60 คำ"
- ดาวสี `highlight` เมื่อจบหมวดหมู่ครบ

### 4.4 Featured Word Card (หัวใจของหน้า)

**ส่วนหัว**
- ชื่อคำ (display) + ปุ่มหัวใจ (บันทึก) มุมขวา
- Chip: `หมวด: การทักทาย` (พื้น `surface`) · `ระดับ: พื้นฐาน` (พื้น `secondary`)
- ปุ่ม "คำถัดไป ›" และ "สุ่มคำ 🎲"

**3D Avatar Viewer** (Unity WebGL)

| ส่วน | พฤติกรรม |
|---|---|
| พื้นที่แสดงผล | อัตราส่วน 16:9, พื้น `#EEF1F6` หรือ `surface` อ่อน |
| ควบคุม | ▶/⏸ เล่น-หยุด · แถบเวลา (scrub ได้) · ความเร็ว 0.5x / 1x · ปุ่มเล่นซ้ำ |
| มุมมอง | ลากเพื่อหมุนกล้อง, scroll/pinch เพื่อซูม, ปุ่ม "มุมหน้า / ข้าง / ซูมมือ" |
| ปุ่ม AR | "ดูแบบ AR" → เปิดกล้อง (WebXR/AR.js) |
| Loading | skeleton + spinner สี `primary` + ข้อความ "กำลังโหลดโมเดล…" |
| Error | ไอคอนเตือน + "โหลดโมเดลไม่สำเร็จ" + ปุ่ม "ลองใหม่" + แสดงภาพนิ่ง/วิดีโอสำรอง |
| ไม่รองรับ WebGL/AR | ซ่อนปุ่ม AR และบอกเหตุผลสั้น ๆ |

**แท็บรายละเอียด (4 แท็บตามที่ต้องการ)**

| แท็บ | เนื้อหา |
|---|---|
| **รายละเอียด** | ความหมายของคำ · หมวด/ระดับ · คำอธิบายสั้น 1–2 ประโยค · หมายเหตุการใช้ (เช่น ใช้ได้ทั้งทักทายและบอกลา) |
| **ขั้นตอนการทำท่า** | รายการขั้นตอนเรียงลำดับ 1→N แต่ละข้อมี: รูปมือ (Hand shape) · ตำแหน่ง · ทิศทางการเคลื่อนไหว · สีหน้า; กดข้อใดข้อหนึ่ง → Avatar เล่นเฉพาะช่วงนั้น (step-by-step) |
| **ตัวอย่างการใช้** | ประโยคตัวอย่าง 2–3 ประโยค เช่น "สวัสดีครับ/ค่ะ" พร้อมปุ่ม ▶ เล่นท่าทางประโยค (เชื่อมกับชุดประโยคพื้นฐาน 10–20 รูปแบบ) |
| **คำศัพท์ที่เกี่ยวข้อง** | การ์ดเล็กเลื่อนแนวนอน (ขอบคุณ, ลาก่อน, ขอโทษ ฯ) กดแล้วโหลดคำนั้นใน Viewer |

**Tabs states:** Active = พื้น `secondary` + ตัวหนา + เส้นใต้ 3px สี `accent` · Hover = พื้นอ่อน · Focus = outline · เปลี่ยนแท็บแบบ fade 250ms

**ตัวอย่างเนื้อหาแท็บ "ขั้นตอนการทำท่า" (mock)**
```
1. ยกมือขวาขึ้นระดับหน้าผาก ฝ่ามือหันออก นิ้วทั้งห้าชิดกัน
2. แตะปลายนิ้วที่หน้าผากเบา ๆ
3. เคลื่อนมือออกด้านหน้าเป็นเส้นโค้งเล็กน้อย
4. ยิ้มและสบตา (สีหน้าเป็นส่วนหนึ่งของภาษามือ)
```
> เนื้อหาท่าจริงต้องตรวจกับแหล่งอ้างอิงภาษามือไทยที่เชื่อถือได้ (หรือผู้เชี่ยวชาญ) ก่อนใช้งาน ตัวอย่างข้างบนใช้เพื่อแสดงรูปแบบเท่านั้น

### 4.5 Category Card (หมวดหมู่)
- ขนาด 160×120px, ไอคอน + ชื่อหมวด + "N คำ"
- พื้น `surface` / hover ยก 2px + shadow
- หมวดเริ่มต้นตามขอบเขตโครงงาน: **การทักทาย · การซื้อขาย · การขอความช่วยเหลือ** + (เสริม) ครอบครัว · ตัวเลข · อาหาร · สถานที่
- Badge ระดับ: พื้นฐาน / กลาง / ขั้นสูง

### 4.6 Word Card (การ์ดคำย่อ)
- Thumbnail (ภาพนิ่งของท่า) · ชื่อคำ · chip หมวด · หัวใจบันทึก · ไอคอนดาวถ้าเรียนจบ
- Hover: เล่น preview GIF/loop สั้น ๆ (ถ้า performance ไหว)
- Click: โหลดคำนั้นใน Featured Card (ไม่ต้องเปลี่ยนหน้า) หรือไป `/vocab/:id` บนมือถือ

### 4.7 ปุ่ม

| Variant | Visual | ใช้เมื่อ |
|---|---|---|
| Primary | พื้น `primary-strong` ตัวอักษรขาว | เริ่มเรียน, ดูแบบ AR |
| Secondary | พื้น `secondary` ตัวอักษร `text` | คำถัดไป, ดูทั้งหมด |
| Ghost | โปร่ง เส้นขอบ `border` | ตัวเลือกรอง |
| Icon | วงกลม 40px | หัวใจ, play, ปิด |

States: Hover (เข้มขึ้น) · Active (กดลง scale .98) · Disabled (opacity .5, ไม่ตอบสนอง) · Loading (spinner แทนข้อความ) · Focus (outline 2px `accent`)

## 5. การทำงานเชิงโต้ตอบ (Interaction Flow)

1. เข้าหน้า → โหลดคำแนะนำวันนี้ + Viewer เริ่มที่ท่าพร้อม (idle pose) ยังไม่ autoplay (ให้ผู้ใช้กด ▶)
2. พิมพ์ค้นหา → suggestion → เลือก → Featured Card เปลี่ยนเป็นคำนั้น
3. กดหมวด → ไป `/vocab?category=...`
4. กดหัวใจ → บันทึก (optimistic update) + toast "บันทึกแล้ว"
5. ดูครบทุกขั้นตอน + กดเล่นอย่างน้อย 1 รอบ → ติ๊กว่า "เรียนแล้ว" และ progress เพิ่ม
6. กด "ดูแบบ AR" → ขอสิทธิ์กล้อง → วางโมเดลบนพื้นผิว; ถ้าปฏิเสธ → แสดงคำแนะนำเปิดสิทธิ์

## 7. Accessibility

- Landmark: `<header>` `<nav aria-label="เมนูหลัก">` `<main>`
- Search: `role="search"`, suggestion ใช้ `role="listbox"` + ลูกศรขึ้นลง/Enter/Esc
- Tabs: `role="tablist/tab/tabpanel"`, ลูกศรซ้ายขวาเปลี่ยนแท็บ
- Viewer: `aria-label="โมเดล 3 มิติแสดงท่าทางคำว่า สวัสดี"` + ปุ่มควบคุมทุกปุ่มใช้คีย์บอร์ดได้ (Space = เล่น/หยุด)
- ให้ **คำบรรยายข้อความของท่า** ในแท็บขั้นตอน เพื่อไม่ต้องพึ่งภาพอย่างเดียว
- ไม่ใช้สีอย่างเดียวสื่อความหมาย (เช่น "เรียนแล้ว" = ไอคอนดาว + ข้อความ)
- เคารพ `prefers-reduced-motion` (ปิด auto-preview และ animation ตกแต่ง)
- เป้าหมาย WCAG 2.1 AA
