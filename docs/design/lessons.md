# แท็บ "บทเรียน" (Lessons) — Spec ฟีเจอร์

> เว็บแอปเรียนรู้ภาษามือไทยด้วย 3D Avatar (Unity) และ AR
> เอกสารนี้ครอบคลุม **เฉพาะแท็บบทเรียน** (แท็บอื่นเพื่อนเป็นคนทำ)

---

## 1. ภาพรวม

แท็บบทเรียนคือจุดที่ผู้ใช้ **เรียนคำศัพท์เป็นหมวด ๆ** และ **ทำแบบฝึกหัด** เพื่อทดสอบความเข้าใจ เป็นส่วนหลักที่วัดผล Learning Effectiveness ของโครงงาน

**เป้าหมายของผู้ใช้**
- เลือกหมวดบทเรียนที่ต้องการ และเห็นความคืบหน้าของตัวเอง
- ดูท่าภาษามือผ่าน Avatar 3 มิติ แล้วจำให้ได้
- ทำแบบฝึกหัดหลายรูปแบบ และได้ผลลัพธ์ทันที

**ขอบเขตเนื้อหา:** คำศัพท์ในชีวิตประจำวัน (การทักทาย, การซื้อขาย, การขอความช่วยเหลือ ตามบทคัดย่อ)

## 3. Flow การใช้งาน

```
หน้ารายการบทเรียน
   ├─► กดการ์ดบทเรียน ─► หน้าเรียนคำศัพท์ (Flashcard + Avatar 3D)
   │                          └─► จบบท ─► แนะนำทำแบบฝึกหัดของบทนั้น
   └─► กด "เริ่มฝึก" ─► หน้าแบบฝึกหัด ─► หน้าสรุปผล ─► กลับ/ทำซ้ำ
```

### 3.1 หน้าเรียนคำศัพท์ (ฝึกฝนคำศัพท์)
- แสดงคำศัพท์ทีละคำ พร้อม **Avatar 3D เล่นท่าภาษามือ**
- ปุ่ม: เล่นซ้ำ, ช้า/ปกติ, หมุนมุมมอง, คำก่อนหน้า/ถัดไป
- ปุ่ม **"ดูใน AR"** ลิงก์ไปยังแท็บ AR โหมดพร้อมส่งคำศัพท์นั้นไป
- ปุ่ม "จำได้แล้ว / ยังไม่แน่ใจ" เพื่อคำนวณ progress
- แถบความคืบหน้า เช่น 3/10

### 3.2 แบบฝึกหัด 3 รูปแบบ (จาก Wireframe)

| ประเภท | วิธีเล่น | จำนวนข้อ |
|--------|---------|---------|
| **ฝึกจำท่าทาง** | ดู Avatar ทำท่า แล้วเลือกคำตอบที่ถูกต้อง (ตัวเลือก 4 ข้อ) | 5 |
| **ฟังและเลือกภาพ** | ฟัง/อ่านคำศัพท์ แล้วเลือกภาพท่ามือที่ตรงกัน | 5 |
| **เรียงลำดับท่าทาง** | เรียงขั้นตอนของท่า หรือคำในประโยคให้ถูกลำดับ (drag & drop) | 5 |

**พฤติกรรมร่วม:** feedback ทันทีหลังตอบ (ถูก/ผิด + ดูท่าที่ถูกซ้ำ), แถบความคืบหน้าบนหัว, ออกกลางคันได้และบันทึกต่อ

### 3.3 หน้าสรุปผล
- คะแนน เช่น 4/5 และข้อที่ผิด พร้อมปุ่มดูท่าที่ถูกต้อง
- ปุ่ม "ทำซ้ำ" / "ไปบทถัดไป" / "กลับหน้ารายการ"

## 4. โครงสร้างข้อมูล (เสนอ)

```json
{
  "lesson": {
    "id": "01",
    "title": "การทักทาย",
    "coverImage": "url",
    "category": "greeting",
    "wordIds": ["w001", "w002"]
  },
  "word": {
    "id": "w001",
    "thai": "สวัสดี",
    "avatarAnimationId": "anim_hello",
    "thumbnail": "url"
  },
  "progress": {
    "userId": "u1",
    "lessonId": "01",
    "learnedWordIds": ["w001"],
    "percent": 10
  },
  "exerciseResult": {
    "userId": "u1",
    "type": "recall | listen-pick | sequence",
    "lessonId": "01",
    "score": 4,
    "total": 5,
    "takenAt": "ISO-8601"
  }
}
```

> เก็บ `exerciseResult` ไว้ เพราะใช้วิเคราะห์ Learning Effectiveness ตามแผนการทดลองได้

**สูตร progress:** `percent = learnedWords / totalWords × 100` (อาจถ่วงด้วยคะแนนแบบฝึกหัดภายหลัง)

## 5. มู้ดโทนและสไตล์ (อ้างอิง Moodboard "ดอกบัว")

**คอนเซ็ปต์:** *Speak with hands, Connect with hearts* — อบอุ่น สงบ ละมุน เป็นมิตร มีกลิ่นอายไทย

### 5.1 พาเลตต์ (ประมาณจาก Moodboard)

| บทบาท | สี | ค่าประมาณ |
|-------|-----|----------|
| Primary (ปุ่มหลัก, active) | เขียวเสจ | `#8A9A6E` |
| Secondary (chip, พื้นการ์ด) | เขียวอ่อน | `#B5C49A` |
| Accent (ไฮไลต์, progress) | ชมพูดอกบัว | `#E88FB8` |
| Surface อ่อน | ชมพูจาง | `#F5D9E6` |
| Background | ครีม | `#FBF6EC` |
| Highlight พิเศษ (ดาว/เสร็จสมบูรณ์) | ทอง | `#D4AF37` |
| Text หลัก | เขียวเข้มเกือบดำ | `#2F3A26` |

> ค่าสีเป็นการประมาณจากภาพ แนะนำใช้ eyedropper ใน Canva เพื่อดึงค่าจริง

### 5.2 การใช้งานสีในหน้านี้
- **Sidebar:** พื้นครีม/เขียวอ่อน, เมนู active (บทเรียน) = เขียวเสจเข้ม + ตัวอักษรขาว
- **Filter chip:** active = เขียวเสจ, inactive = ชมพูจาง
- **การ์ดบทเรียน:** พื้นครีมขาว มุมโค้ง 20–24px เงาบาง ๆ
- **Progress bar:** ราง = ชมพูจาง, แท่ง = เขียวเสจ หรือไล่ชมพู→ทอง เมื่อครบ 100%
- **ปุ่ม "เริ่มฝึก":** เขียวเสจ ตัวอักษรขาว (แทนปุ่มดำใน wireframe)

### 5.3 องค์ประกอบตกแต่ง
- ลายดอกบัวเส้นบางโปร่งเป็นพื้นหลังจาง ๆ (opacity 5–10%) ไม่ให้แย่งความสนใจจากเนื้อหา
- รูปปกแต่ละบทใช้สไตล์ภาพประกอบเดียวกัน (ตัวละครเขียวในโมดบอร์ด/มือ/ดอกบัว)
- ไอคอนมือแบบ line ปลายมน
- Micro-interaction: บัวบานเล็ก ๆ เมื่อทำบทเสร็จ

### 5.4 ตัวอักษร
- ภาษาไทย: **Prompt** หรือ **Noto Sans Thai Looped** (อ่านง่าย มีความเป็นมิตร)
- หัวข้อ 24–28px / ชื่อการ์ด 18–20px / เนื้อหา 16px / ข้อความรอง ไม่ต่ำกว่า 14px

## 6. Design Critique (Wireframe ปัจจุบัน)

### ภาพรวม
โครงสร้างชัดเจน ลำดับ "เลือกบท → ดู progress → ฝึกเพิ่ม" เข้าใจง่าย จุดที่ควรปรับมากที่สุดคือ **ความสอดคล้องกับมู้ดโทนดอกบัว** และ **ความสม่ำเสมอของการ์ด**

### Usability
| ข้อสังเกต | ความรุนแรง | คำแนะนำ |
|-----------|-----------|---------|
| Filter chip มี 4 หมวด แต่บทเรียนมี 6 (ไม่มี โรงเรียน/การเรียน, การขอความช่วยเหลือ) | 🟡 | ให้ chip ตรงกับหมวดทั้งหมด หรือเลื่อนแนวนอนได้ |
| การ์ดมีแค่ใบแรกที่มีช่องใส่รูป ใบอื่นเว้นว่าง | 🟡 | ให้ทุกใบมีรูปปกขนาดเท่ากัน |
| ไม่รู้ว่าบทไหนล็อก/ยังไม่เริ่ม/เรียนจบ มีแต่ % | 🟡 | เพิ่มสถานะ: ยังไม่เริ่ม / กำลังเรียน / เสร็จ + ปุ่ม "เรียนต่อ" |
| ไม่มีบทเรียนเรื่อง การซื้อขาย ทั้งที่อยู่ในขอบเขตโครงงาน | 🟡 | พิจารณาเพิ่มเป็นบท 07 |
| "แบบฝึกหัดแนะนำ" ไม่บอกว่าเกี่ยวกับบทไหน | 🟡 | ใส่ป้าย เช่น "จากบทการทักทาย" |
| แบบฝึกหัดอาจซ้ำซ้อนกับแท็บ "ฝึกทบทวน" ของเพื่อน | 🟡 | คุยกับเพื่อนว่าแบ่งหน้าที่กันอย่างไร: แบบฝึกหัดผูกกับบท vs ทบทวนรวม |
| Search bar ไม่บอกชัดว่าค้นในบทเรียนหรือทั้งแอป | 🟢 | ปรับ placeholder เป็น "ค้นหาบทเรียนหรือคำศัพท์" |

### Visual Hierarchy
- **สายตาไปที่ไหนก่อน:** ปุ่ม sidebar เมนู active สีม่วงเข้ม และ chip "ทั้งหมด" สีน้ำตาลเข้ม ซึ่งเข้มกว่าเนื้อหาหลัก
- **การอ่าน:** ซ้าย→ขวา บน→ล่าง ดี แต่ส่วน "แบบฝึกหัดแนะนำ" ห่างจากหัวข้อน้อยและตัวหัวข้อเล็ก
- **เน้นไม่ตรงจุด:** ข้อความ "คำศัพท์ 10 คำ" เล็กมาก ควรเพิ่มขนาด ส่วน % ควรเด่นกว่านี้

### ความสอดคล้อง
| องค์ประกอบ | ปัญหา | คำแนะนำ |
|-----------|-------|---------|
| สีหลัก | ม่วง/น้ำตาล/เขียวเข้ม/ดำ ปนกัน ไม่เข้ากับธีมบัวชมพู-เขียว | ใช้พาเลตต์ในข้อ 5 |
| ปุ่มดำ "เริ่มฝึก" | หนักและแข็งเกินโทนนุ่ม ๆ | เปลี่ยนเป็นเขียวเสจ |
| ระยะและมุมการ์ด | ขนาดการ์ดและตำแหน่งข้อความไม่เท่ากันเล็กน้อย | ใช้ grid และ spacing เดียวกัน (เช่น 8px) |
| Progress 80% เท่ากันทุกใบ | เป็นข้อมูลตัวอย่าง | ใช้ค่าจริงตอน implement |

### การเข้าถึง (Accessibility)
- **Contrast:** ตัวอักษรบนพื้นเทา และ progress สีเขียวเข้มบนรางชมพูจางผ่านได้ แต่ chip ชมพูอ่อน + ตัวอักษรดำควรตรวจ ถ้าเปลี่ยนสีต้องให้ได้ ≥ 4.5:1 สำหรับข้อความปกติ
- **ขนาดข้อความ:** ข้อความรองต่ำกว่า 14px ควรขยาย
- **Touch target:** ปุ่ม "เริ่มฝึก" และ chip ควรสูงอย่างน้อย 44px
- **ไม่พึ่งสีอย่างเดียว:** สถานะ/ความถูกผิดในแบบฝึกหัดต้องมีไอคอนหรือข้อความประกอบ
- **วิดีโอ/Avatar:** มีคำบรรยายตัวอักษรของคำศัพท์ และ alt text ให้รูปทุกใบ ผู้ใช้หูหนวกต้องไม่ต้องพึ่งเสียง ดังนั้นแบบ "ฟังและเลือกภาพ" ควรมีทางเลือกเป็นข้อความ/ภาพแทนเสียงเสมอ

### สิ่งที่ทำได้ดี
- โครงสร้าง 3 คอลัมน์ของการ์ดอ่านง่าย สแกนเร็ว
- Progress bar ในการ์ดให้แรงจูงใจชัดเจน
- แบบฝึกหัดมีหลายรูปแบบ (จำ/ฟัง/เรียง) ช่วยให้ไม่น่าเบื่อ
- มีค้นหา + กรองหมวด เหมาะกับจำนวนบทที่จะเพิ่มขึ้น

### ลำดับความสำคัญในการแก้
1. **ปรับสีและสไตล์ให้เข้ากับมู้ดโทนดอกบัว** ทำให้ทั้งแท็บดูเป็นเอกลักษณ์เดียวกัน
2. **ทำให้การ์ดสม่ำเสมอ** (รูปปก, สถานะ, ปุ่มเรียนต่อ) และให้ chip ครบทุกหมวด
3. **ชี้แจงความสัมพันธ์กับแท็บฝึกทบทวนและ AR โหมด** เพื่อไม่ให้ฟีเจอร์ซ้ำกัน

## 10. คำถามที่ต้องตกลงกับทีม

1. ผู้ใช้ต้องเรียนบทก่อนหน้าให้จบก่อนปลดล็อกบทถัดไปหรือไม่
2. แบบฝึกหัดในแท็บนี้ต่างจากแท็บ "ฝึกทบทวน" อย่างไร
3. ต้องมีระบบล็อกอินเพื่อเก็บ progress หรือเก็บในเครื่องก่อน
4. จะเพิ่มบทเรียน "การซื้อขาย" หรือไม่
