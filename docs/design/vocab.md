# Spec: หน้า "คำศัพท์" (Vocabulary Page)

> เอกสารนี้สำหรับทีมใช้ร่วมกัน ครอบคลุมเฉพาะ **หน้าคำศัพท์** ตาม wireframe ที่แนบ
> หน้าอื่น (หน้าแรก / บทเรียน / ฝึกทบทวน / AR โหมด) ทำโดยคนอื่น ให้ใช้ **Design Tokens** และ **Layout Shell** ในเอกสารนี้ร่วมกัน เพื่อให้หน้าตาเหมือนกันทั้งเว็บ

---

## 1. ภาพรวมโครงงาน

เว็บแอปพลิเคชันสำหรับเรียนรู้และสื่อสารภาษามือไทย ด้วย 3D Visualization และ Augmented Reality (AR)

โมดูลหลัก
1. แสดงท่าทางภาษามือผ่านอวตาร 3 มิติ (สร้างด้วย Unity)
2. เลือกคำศัพท์และประโยคพื้นฐานจากฐานข้อมูลภาษามือไทย
3. แสดงผลแบบ AR ผ่านเว็บเบราว์เซอร์

ขอบเขต: คำศัพท์ในชีวิตประจำวัน เช่น การทักทาย การซื้อขาย การขอความช่วยเหลือ
การประเมิน: Learning Effectiveness และ Usability

**หน้าคำศัพท์มีหน้าที่:** ให้ผู้ใช้เรียกดูคำศัพท์แยกตามหมวด ค้นหาคำ และกดเล่นวิดีโอ/อวตารเพื่อดูท่าภาษามือของคำนั้น

## 2. Design Tokens (สีตาม Moodboard)

| บทบาท | สี | HEX | CSS variable |
|---|---|---|---|
| Primary (ปุ่มหลัก, active) | เขียวเสจ | `#8A9A6E` | `--color-primary` |
| Secondary (chip, พื้นการ์ด) | เขียวอ่อน | `#B5C49A` | `--color-secondary` |
| Accent (ไฮไลต์, progress) | ชมพูดอกบัว | `#E88FB8` | `--color-accent` |
| Surface อ่อน | ชมพูจาง | `#F5D9E6` | `--color-surface` |
| Background | ครีม | `#FBF6EC` | `--color-bg` |
| Highlight พิเศษ (ดาว/เสร็จสมบูรณ์) | ทอง | `#D4AF37` | `--color-gold` |
| Text หลัก | เขียวเข้มเกือบดำ | `#2F3A26` | `--color-text` |

```css
:root {
  --color-primary:   #8A9A6E;
  --color-secondary: #B5C49A;
  --color-accent:    #E88FB8;
  --color-surface:   #F5D9E6;
  --color-bg:        #FBF6EC;
  --color-gold:      #D4AF37;
  --color-text:      #2F3A26;

  --radius-card: 16px;
  --radius-chip: 999px;
  --shadow-card: 0 2px 8px rgba(47, 58, 38, 0.08);
  --font-th: "Noto Sans Thai", "Prompt", "Sarabun", sans-serif;
}
```

**หมายเหตุเรื่องความอ่านง่าย:** ข้อความสีขาวบน `#8A9A6E` คอนทราสต์ค่อนข้างต่ำ
แนะนำใช้ตัวอักษร `--color-text` (`#2F3A26`) บนปุ่ม Primary หรือใช้เฉดเข้มกว่าเล็กน้อยสำหรับ hover/active ถ้าต้องการตัวอักษรขาว

## 3. Layout (ตาม Wireframe)

```
┌──────────────┬──────────────────────────────────────────┐
│ [โลโก้]   ‹  │  [🔍 ค้นหาคำศัพท์...]              (👤)   │  ← Top bar
│              ├──────────────────────────────────────────┤
│ หน้าแรก      │            หมวด...                       │
│ ▌คำศัพท์ ◄   │  [card] [card] [card] [card]             │
│ บทเรียน      │  vocab  vocab  vocab  vocab              │
│ ฝึกทบทวน     │  อธิบาย อธิบาย อธิบาย อธิบาย             │
│ AR โหมด      │            หมวด...                       │
│              │  [card] [card] [card] [card]             │
└──────────────┴──────────────────────────────────────────┘
```

### 3.1 Sidebar (Shared Shell: ทุกหน้าใช้ร่วมกัน)
- ด้านบน: ช่องโลโก้ (pill) + ปุ่มพับ/ขยาย sidebar (`‹`) มุมขวาบน
- เมนู 5 รายการ เรียงลงมา: **หน้าแรก, คำศัพท์, บทเรียน, ฝึกทบทวน, AR โหมด**
- เมนูปกติ: พื้น `--color-secondary`, ตัวอักษร `--color-text`
- เมนู active (หน้าคำศัพท์): พื้น `--color-primary`, ตัวอักษรหนัก (font-weight 600)
- พื้น sidebar: `--color-surface` หรือครีมเข้มขึ้นเล็กน้อย
- เมื่อพับ: แสดงเฉพาะไอคอน (ถ้ายังไม่มีไอคอน ให้ใช้ตัวอักษรแรกชั่วคราว)

### 3.2 Top bar
- ช่องค้นหา (ซ้าย–กลาง): placeholder "ค้นหาคำศัพท์..." + ไอคอนแว่นขยาย ทรง pill
- Avatar ผู้ใช้ (ขวาสุด): วงกลม ไอคอนคน กดเปิดเมนูโปรไฟล์ (ทำโดยทีม shell)
- พื้น: `--color-bg`

### 3.3 Content area
- พื้น `--color-bg` (ครีม)
- แบ่งเป็น **section ตามหมวด** แต่ละ section มีหัวข้อ "หมวด: …" อยู่กึ่งกลาง/ชิดซ้าย (wireframe วางกลาง แนะนำชิดซ้ายเมื่อหน้าจอเล็ก)
- ใต้หัวข้อเป็น **grid การ์ดคำศัพท์ 4 คอลัมน์** (desktop)

| Breakpoint | คอลัมน์ | Sidebar |
|---|---|---|
| ≥ 1024px | 4 | แสดงเต็ม |
| 768–1023px | 3 | พับเป็นไอคอน |
| 480–767px | 2 | เมนูล่าง/Drawer |
| < 480px | 1–2 | Drawer |

## 4. Component: Vocab Card

```
┌─────────────────┐
│                 │
│   [ภาพ/อวตาร    │  ← พื้นที่ preview (อัตราส่วน ~ 4:5)
│    ท่ามือ]      │
│                 │
│ ▶               │  ← แถบล่างพื้น secondary + ปุ่ม play
└─────────────────┘
   คำศัพท์ (thai_text)
   คำอธิบาย (thsl_gloss)
```

- การ์ด: มุมโค้ง `--radius-card`, พื้นอ่อน, เงา `--shadow-card`
- พื้นที่ preview: thumbnail ภาพนิ่งของอวตาร (หรือรูปท่ามือ) ก่อนเล่น
- แถบล่าง: พื้น `--color-secondary` โปร่ง ๆ, ปุ่ม ▶ วงกลมเล็กซ้ายล่าง
- ใต้การ์ด: บรรทัดแรก = `thai_text` (ตัวหนา), บรรทัดสอง = `thsl_gloss` (ตัวเล็ก/สีจางกว่า)
- **รูปใน wireframe (Dora) เป็น placeholder เท่านั้น** ห้ามใช้ภาพลิขสิทธิ์ในงานจริง ให้ใช้ภาพจากอวตาร Unity

### States
| State | พฤติกรรม |
|---|---|
| default | แสดง thumbnail + ▶ |
| hover | ยกเงาขึ้น, ขอบ `--color-primary` |
| focus (คีย์บอร์ด) | outline 2px `--color-accent` |
| playing | ▶ เปลี่ยนเป็น ⏸, ขอบ `--color-accent` |
| loading | skeleton สีครีมเข้ม |
| error | ไอคอนเตือน + ข้อความ "โหลดไม่สำเร็จ" + ปุ่มลองใหม่ |

### การเล่นท่าภาษามือ
- กด ▶ เล่นแบบ inline ในการ์ด **หรือ** เปิด modal ขนาดใหญ่ (แนะนำ modal เพราะดูท่ามือชัดกว่า)
- Modal ควรมี: วิดีโอ/อวตาร, `thai_text`, `thsl_gloss`, `facial_expression` (ถ้ามี), ปุ่มเล่นซ้ำ, ปุ่มช้า (0.5x), ปุ่มปิด
- ปุ่ม "ดูแบบ AR" ลิงก์ไปหน้า AR โหมด (ส่ง `vocab_id` ไปด้วย)

## 5. ข้อมูล (Data Contract)

ข้อมูลมาจาก Google Sheet สองชุด

### 5.1 ชีต คำศัพท์ (`V001–V050`)
| ฟิลด์ | ความหมาย |
|---|---|
| `vocab_id` | รหัสคำ เช่น `V001` |
| `thai_text` | คำไทย |
| `category` | หมวด |
| `thsl_gloss` | คำอธิบายท่าภาษามือ (gloss) |

### 5.2 ชีต ประโยค (`S001–S020`)
ฟิลด์เพิ่ม: `facial_expression` (สีหน้าประกอบ), `ref` (ลิงก์วิดีโออ้างอิง)
ใช้ในหน้า **บทเรียน** เป็นหลัก หน้าคำศัพท์ใช้ชีต V เป็นหลัก

### 5.3 JSON ที่แนะนำ

```json
{
  "vocab_id": "V001",
  "thai_text": "สวัสดี",
  "category": "คำทักทายและคำพื้นฐาน",
  "thsl_gloss": "สวัสดี",
  "facial_expression": null,
  "thumbnail_url": "/assets/thumbs/V001.png",
  "video_url": "/assets/videos/V001.mp4",
  "avatar_clip_id": "V001"
}
```

> `thumbnail_url`, `video_url`, `avatar_clip_id` ยังไม่มีในชีต ต้องตกลงกับทีมอวตาร/Unity ว่าจะตั้งชื่อไฟล์ตาม `vocab_id`

### 5.4 หมวดหมู่ (หมวด → section)

| ลำดับ | หมวด (`category`) | ช่วง ID | จำนวนปัจจุบัน |
|---|---|---|---|
| 1 | คำทักทายและคำพื้นฐาน | V001–V009 | 9 |
| 2 | บุคคลและครอบครัว | V010–V017 | 8 |
| 3 | อาหารและเครื่องดื่ม | V018–V025 | 8 |
| 4 | เวลาและตัวเลข | V026–V034 | 9 |
| 5 | สถานที่และการเดินทาง | V035–V042 | 8 |
| 6 | อารมณ์และความรู้สึก | V043–V050 | 8 (ยังไม่มีคำ) |

- หมวดที่ยังไม่มีเนื้อหา (แถวว่าง) ให้ **ซ่อน** หรือแสดงป้าย "เร็ว ๆ นี้" ไม่ต้องแสดงการ์ดว่าง
- ชื่อหมวดทั้งหมดเก็บเป็นค่าคงที่ที่เดียว (`categories.ts`) เพื่อให้ทุกหน้าใช้ตรงกัน

### 5.5 สี chip ของหมวด (อิงจาก palette หลัก)

ในชีตแต่ละหมวดมีสี pastel ต่างกัน แต่ในเว็บให้ใช้สีจาก palette เพื่อความเป็นหนึ่งเดียว
ถ้าต้องการแยกหมวดด้วยสี ให้ใช้เฉดจาก token ดังนี้

| หมวด | พื้น chip | ตัวอักษร |
|---|---|---|
| คำทักทายและคำพื้นฐาน | `#B5C49A` | `#2F3A26` |
| บุคคลและครอบครัว | `#F5D9E6` | `#2F3A26` |
| อาหารและเครื่องดื่ม | `#E88FB8` (โปร่ง 40%) | `#2F3A26` |
| เวลาและตัวเลข | `#8A9A6E` (โปร่ง 40%) | `#2F3A26` |
| สถานที่และการเดินทาง | `#B5C49A` (โปร่ง 60%) | `#2F3A26` |
| อารมณ์และความรู้สึก | `#F5D9E6` | `#2F3A26` |

## 6. ฟังก์ชันของหน้า

1. **แสดงรายการตามหมวด:** โหลดคำศัพท์ทั้งหมด แล้ว group ตาม `category`
2. **ค้นหา:** กรองแบบ real-time (debounce ~300ms) จาก `thai_text` และ `thsl_gloss`
   - ผลลัพธ์แสดงเป็นการ์ดต่อเนื่อง (ซ่อนหัวหมวดที่ไม่มีผล)
   - ไม่พบ: แสดง "ไม่พบคำศัพท์ที่ค้นหา"
3. **เล่นท่าภาษามือ:** กด ▶ ตามหัวข้อ 4
4. **ตัวกรองหมวด (ตัวเลือกเสริม):** แถบ chip ด้านบนเลื่อนไปยังหมวดนั้น
5. **คำที่เรียนแล้ว (ตัวเลือกเสริม):** แสดงดาว `--color-gold` เมื่อผู้ใช้ดูครบ/ทำแบบฝึกหัดผ่าน (ประสานกับหน้า "ฝึกทบทวน")

## 8. Accessibility & UX

- ปุ่ม/การ์ดโฟกัสด้วยคีย์บอร์ดได้ทั้งหมด (Tab, Enter, Space)
- ใส่ `aria-label` ที่ปุ่มเล่น เช่น "เล่นท่าภาษามือคำว่า สวัสดี"
- วิดีโอต้องไม่เล่นอัตโนมัติพร้อมเสียง; ถ้ามีเสียงให้มีปุ่มปิดเสียง
- ขนาดปุ่มกดอย่างน้อย 44×44px บนมือถือ
- ผู้ใช้หลักรวมผู้บกพร่องทางการได้ยิน → **อย่าสื่อสารด้วยเสียงอย่างเดียว** ใช้ข้อความ/ภาพประกอบเสมอ
- ฟอนต์ไทยขนาดอย่างน้อย 16px, line-height ≥ 1.5

## 9. ขอบเขตงานของเรา vs. คนอื่น

| ส่วน | ผู้รับผิดชอบ |
|---|---|
| หน้า `/vocab` (เอกสารนี้) | **เรา** |
| Sidebar / Top bar (Shell) | ตกลงกันในทีม (ควรเป็น component เดียวกัน) |
| หน้าแรก, บทเรียน, ฝึกทบทวน, AR โหมด | คนอื่น |
| อวตาร 3D / คลิปท่ามือ (Unity) | ทีมอวตาร |
| ข้อมูลคำศัพท์ (Sheet) | ทีมข้อมูล |

### Checklist ก่อนรวมงาน
- [ ] ใช้ CSS variables จากหัวข้อ 2 ครบ ไม่ hardcode สี
- [ ] Sidebar เมนู active ถูกต้อง (คำศัพท์ = active ในหน้านี้)
- [ ] ชื่อหมวดตรงกับค่าคงที่กลาง
- [ ] รูป placeholder (Dora) ถูกแทนที่ด้วยภาพจริง
- [ ] ทดสอบ responsive ทั้ง 4 breakpoint
- [ ] ตกลงรูปแบบชื่อไฟล์ thumbnail/video กับทีมอวตาร
