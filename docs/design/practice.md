# หน้า 5: ฝึกทบทวน (Review Practice)

## 1. ภาพรวม

หน้าสำหรับให้ผู้เรียนทบทวนคำศัพท์ที่เรียนมาแล้ว โดยแสดงคำศัพท์ภาษาไทย 1 คำ พร้อมภาพประกอบและเสียง จากนั้นให้เลือกคำตอบภาษาอังกฤษที่ถูกต้องจาก 3 ตัวเลือก

- **เมนูที่ active:** ฝึกทบทวน
- **ปุ่มย้อนกลับ:** กลับไปหน้าคำศัพท์
- **ไฟล์ต้นแบบ:** `review-practice.html`

## 2. พาเลตต์สี (ประมาณจาก Moodboard)

> **ข้อบังคับ:** ใช้เฉพาะสีในตารางนี้เท่านั้น ห้ามเปลี่ยนหรือเพิ่มสีอื่น

| บทบาท | สี | ค่าประมาณ |
|---|---|---|
| Primary (ปุ่มหลัก, active) | เขียวเสจ | `#8A9A6E` |
| Secondary (chip, พื้นการ์ด) | เขียวอ่อน | `#B5C49A` |
| Accent (ไฮไลต์, progress) | ชมพูดอกบัว | `#E88FB8` |
| Surface อ่อน | ชมพูจาง | `#F5D9E6` |
| Background | ครีม | `#FBF6EC` |
| Highlight พิเศษ (ดาว/เสร็จสมบูรณ์) | ทอง | `#D4AF37` |
| Text หลัก | เขียวเข้มเกือบดำ | `#2F3A26` |

### CSS Variables

```css
:root {
  --primary:   #8A9A6E;
  --secondary: #B5C49A;
  --accent:    #E88FB8;
  --surface:   #F5D9E6;
  --bg:        #FBF6EC;
  --gold:      #D4AF37;
  --text:      #2F3A26;
}
```

## 4. องค์ประกอบ (Components)

### 4.1 Sidebar
- โลโก้ (ทรงแคปซูล) ด้านบน
- เมนู 5 รายการ: หน้าแรก, คำศัพท์, บทเรียน, **ฝึกทบทวน (active)**, AR โหมด
- ปุ่ม `‹` / `›` สำหรับย่อ-ขยายเมนู
- จอแคบกว่า 720px ให้ย่อเมนูอัตโนมัติ

### 4.2 Top bar
- ไอคอนโปรไฟล์ผู้ใช้ มุมขวาบน (วงกลม)

### 4.3 การ์ดคำศัพท์
- **ชื่อ:** คำศัพท์ภาษาไทย ตัวใหญ่กึ่งกลาง
- **ปุ่มหัวใจ:** บันทึก/ยกเลิกบันทึกคำศัพท์ (toggle)
- **ภาพประกอบ:** ภาพตัวการ์ตูนประกอบคำศัพท์
- **แถบเสียง:** ปุ่มเล่นเสียงออกเสียงคำภาษาอังกฤษ
- **Chip โจทย์:** ข้อความคำถาม
- **ตัวเลือก:** 3 ปุ่ม เรียงแนวนอน (จอแคบเรียงแนวตั้ง)

### 4.4 ผลลัพธ์และการดำเนินการ
- ข้อความตอบกลับใต้ตัวเลือก (`aria-live="polite"`)
- ปุ่ม **ข้อถัดไป** แสดงหลังตอบ (ข้อสุดท้ายแสดง **ดูผลคะแนน**)

### 4.5 หน้าสรุปผล
- ไอคอนดาวสีทอง
- ข้อความ "ทบทวนครบแล้ว"
- คะแนน เช่น "ได้ 2 จาก 3 ข้อ"
- ปุ่ม **ฝึกอีกครั้ง**

## 5. สถานะของตัวเลือก

| สถานะ | พฤติกรรม |
|---|---|
| ปกติ | พื้น `--surface` ขอบ `--primary` |
| Hover | ขอบเปลี่ยนเป็น `--accent` ยกขึ้นเล็กน้อย |
| ตอบถูก | พื้น `--primary` และแสดง "ถูกต้อง เก่งมาก!" |
| ตอบผิด | ตัวเลือกที่กดเป็น `--accent` ส่วนข้อที่ถูกเป็น `--primary` พร้อมบอกคำตอบ |
| หลังตอบแล้ว | ปุ่มตัวเลือกทั้งหมดกดซ้ำไม่ได้ (disabled) |

---

## 6. ลำดับการทำงาน (Flow)

1. เข้าหน้า แสดงข้อที่ 1
2. ผู้ใช้กดฟังเสียง (ถ้าต้องการ)
3. ผู้ใช้เลือกคำตอบ ระบบตรวจและแสดงผลทันที
4. กด **ข้อถัดไป** เพื่อไปข้อต่อไป และ progress เพิ่มขึ้น
5. ครบทุกข้อ แสดงหน้าสรุปคะแนน
6. กด **ฝึกอีกครั้ง** เพื่อเริ่มใหม่

## 7. ข้อมูลโจทย์ตัวอย่าง

```json
[
  { "th": "สวัสดี",  "en": "Hello",     "choices": ["Hello", "Goodbye", "Thank you"],  "answer": 0 },
  { "th": "ขอบคุณ", "en": "Thank you", "choices": ["Sorry", "Thank you", "Please"],   "answer": 1 },
  { "th": "ลาก่อน", "en": "Goodbye",   "choices": ["Good night", "Welcome", "Goodbye"], "answer": 2 }
]
```

| ฟิลด์ | ความหมาย |
|---|---|
| `th` | คำศัพท์ภาษาไทย (ชื่อบนการ์ด) |
| `en` | คำภาษาอังกฤษ (ใช้เล่นเสียง) |
| `choices` | ตัวเลือก 3 ข้อ |
| `answer` | ลำดับของคำตอบที่ถูก (เริ่มจาก 0) |

## 8. การเข้าถึง (Accessibility)

- ทุกปุ่มมี `aria-label` หรือข้อความที่อ่านได้
- ปุ่มหัวใจใช้ `aria-pressed`
- เมนูปัจจุบันใช้ `aria-current="page"`
- มี focus ring ชัดเจนเมื่อใช้คีย์บอร์ด
- ไม่ใช้สีอย่างเดียวบอกผลถูก/ผิด มีข้อความประกอบเสมอ

---

## 9. หมายเหตุ

- ภาพประกอบในต้นแบบเป็นภาพวาดทั่วไป ไม่ใช้ตัวละครที่มีลิขสิทธิ์ ควรเปลี่ยนเป็นภาพของโปรเจกต์เอง
- ข้อความโจทย์ในรูปต้นแบบเป็น placeholder ("โจทย์อยากถามอะไร") ควรแทนด้วยโจทย์จริงจากฐานข้อมูล
- เสียงในต้นแบบใช้ Web Speech API ของเบราว์เซอร์ ควรเปลี่ยนเป็นไฟล์เสียงจริงเมื่อพัฒนาระบบ
